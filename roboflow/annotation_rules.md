# Roboflow Annotation Rules

## 프로젝트 유형
Object Detection

## 클래스
- clothes: 상의·하의·외투 등 의류
- shoes: 신발. 초기 MVP에서는 "신발 한 짝"을 객체 1개로 정의
- book: 책 1권을 객체 1개로 정의
- kitchenware: 그릇, 컵, 냄비 등
- small_appliance: 드라이기, 전기포트, 토스터 등
- bag: 가방

## 라벨링 원칙
1. 객체 전체가 들어오도록 bounding box를 그린다.
2. 물체 일부만 보이는 경우에도 50% 이상 보이면 라벨링한다.
3. 심하게 겹쳐 경계가 불명확한 물체는 학습 초기 데이터에서 제외한다.
4. 사진 배경, 사람 손, 테이블은 라벨링하지 않는다.
5. 학생마다 같은 물체를 여러 각도·거리·조명에서 촬영한다.
6. 같은 사진을 train/validation/test에 중복 넣지 않는다.

## 추천 데이터 규모
수업 MVP: 클래스당 60~100개 객체
학급 공동 프로젝트: 총 이미지 400~700장
권장 분할: Train 70% / Validation 20% / Test 10%

## 중요한 토론 과제
신발을 "한 짝"으로 셀지 "한 켤레"로 셀지 먼저 정의한다.
AI 모델의 정답은 자연에 존재하는 것이 아니라 프로젝트의 문제 정의에 의해 정해진다.
