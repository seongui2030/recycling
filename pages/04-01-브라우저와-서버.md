# 04-01. 프론트엔드와 백엔드의 역할

> **누가 무엇을 담당하는지 구분하면 웹이 쉬워집니다**

## 🔗 기술을 연결하면 서비스가 됩니다

컴퓨터 비전과 데이터베이스가 있어도 서로 대화하지 못하면 서비스가 되지 않습니다. 이 장에서는 **SDG 9의 디지털 인프라 관점에서 브라우저, 서버, API가 어떻게 연결되는지** 배웁니다.


웹앱을 처음 배우면 “프론트엔드와 백엔드가 무엇인가요?”라는 질문을 만나게 됩니다.

쉽게 비유하면:

- **프론트엔드**: 손님이 보는 매장
- **백엔드**: 매장 뒤에서 주문을 처리하는 주방
- **데이터베이스**: 재료와 주문 기록을 보관하는 창고

우리 프로젝트에서 React 화면은 프론트엔드입니다.

```text
src/App.jsx
src/main.jsx
src/styles.css
```

Vercel의 `api/detect.js`는 서버에서 실행되는 함수입니다.

```text
api/detect.js
```

그리고 Supabase는 데이터베이스와 인증을 담당합니다.

### 전체 구조

```text
[스마트폰 브라우저]
        │
        ├── React 화면
        │
        ├── /api/detect
        │
        └── Supabase Auth / DB
```

중요한 것은 “프론트가 중요하고 백엔드가 중요하다”가 아니라 **각자의 역할을 나누어 안전하고 관리하기 쉽게 만드는 것**입니다.
