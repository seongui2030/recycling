# 05-10. 복붙 후 코드읽기

> **복사는 출발점이고 읽기가 학습입니다**

수업에서는 복사해서 붙여 넣는 과정이 자주 나옵니다.

그때 세 질문을 합니다.

```text
① 이 코드는 무엇을 하나요?
② 입력은 무엇인가요?
③ 결과는 무엇인가요?
```

예를 들어:

```javascript
setImageUrl(dataUrl)
```

를 보면:

- 입력 → `dataUrl`
- 동작 → React 상태 변경
- 결과 → 화면에 사진이 나타남

처럼 설명할 수 있습니다.

이 방법을 모든 코드에 적용할 필요는 없습니다. 한 페이지에서 **중요한 코드 한 줄**만 골라도 충분합니다.

복붙은 손의 작업이고, 코드 읽기는 생각의 작업입니다.
