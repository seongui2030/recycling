## 🧰 배우기 위한 도구를 준비합니다

SDG 4의 교육은 좋은 도구와 편안한 학습 환경에서 시작합니다. VS Code, Git, GitHub, Node.js를 준비하면서 **“나도 디지털 서비스를 만들 수 있다”**는 첫 경험을 시작합니다.


필요한 도구는 많아 보이지만 하나씩 설치하면 됩니다.

## 준비물

- VS Code
- Git
- Git Bash
- Node.js
- Google Chrome 등 브라우저
- GitHub 계정
- Roboflow 계정
- Supabase 계정
- Vercel 계정

## 계정 이름을 기억하세요

```text
GitHub   → 코드 저장
Roboflow → AI 학습과 검출
Supabase → 로그인과 데이터베이스
Vercel   → 웹앱 배포
```

이 네 서비스를 연결하면 하나의 작은 AI 서비스가 됩니다.

## 실습 전 확인

각 도구가 설치되어 있는지 하나씩 체크합니다.

```bash
git --version
node --version
npm --version
```

버전 숫자가 나오면 성공입니다.

버전이 나오지 않아도 걱정하지 마세요. 설치 문제는 코드 문제와 다릅니다. 교사와 함께 먼저 개발 환경부터 해결하면 됩니다.
