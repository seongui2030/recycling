# 06-14. 컴포넌트로 나누기 도전

> **App.jsx가 커지면 화면을 나눌 수 있습니다**

현재 프로젝트는 `App.jsx` 하나에 많은 기능을 담아 두어 수업에서 전체 흐름을 보기 쉽습니다. fileciteturn6file0

하지만 실제 서비스가 커지면 다음처럼 나눌 수 있습니다.

```text
src/components/
├── LoginButton.jsx
├── PhotoUploader.jsx
├── DetectionResult.jsx
└── DonationForm.jsx
```

첨부된 로그인 가이드도 `LoginButton.jsx`, `UserProfile.jsx`처럼 기능별 컴포넌트로 나누어 설명합니다. fileciteturn0file0L67-L105

### 도전

`App.jsx`에서 로그인 영역만 별도의 컴포넌트로 분리해 봅니다.

처음부터 완벽하게 만들 필요는 없습니다.

**작동하는 하나의 파일 → 기능별 여러 파일**이라는 변화 자체가 웹 프레임워크의 중요한 학습입니다.
