# 01-03. 컴퓨터실 실습 약속

> **실수해도 괜찮은 개발자가 되는 연습**

### 약속 1. 복붙은 부끄러운 일이 아닙니다

처음에는 코드를 직접 타이핑하기보다 정확하게 복사하는 것이 좋습니다. 대신 복사한 뒤 **무슨 역할인지 한 줄 설명**해 봅니다.

### 약속 2. 빨간 글씨가 나오면 멈추지 않습니다

에러 메시지는 컴퓨터가 보내는 도움말입니다.

```bash
npm run dev
```

실행했는데 문제가 생겼다면 화면의 마지막 5~10줄을 읽습니다. 특히 `Error`, `failed`, `undefined` 같은 단어를 찾습니다.

### 약속 3. 키는 친구에게 보내지 않습니다

`.env.local`에는 서비스 연결에 필요한 값이 들어갈 수 있습니다. GitHub에 올리지 않습니다.

### 약속 4. AI의 결과를 정답으로 생각하지 않습니다

이 프로젝트에서는 AI가 검출한 결과를 학생이 확인하고 `+ / −` 버튼으로 수정할 수 있습니다. 이것은 기능이면서 동시에 인공지능 윤리 수업의 중요한 메시지입니다.

### 약속 5. 한 번에 하나만 바꿉니다

코드를 여러 곳 동시에 수정하면 무엇 때문에 문제가 생겼는지 알기 어렵습니다.

**한 줄 수정 → 저장 → 실행 → 확인**의 리듬을 지켜 주세요.
