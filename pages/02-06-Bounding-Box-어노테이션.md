# 02-06. Bounding Box 어노테이션

> **사진 속 물체의 위치를 네모 상자로 알려 주기**

Object Detection 학습에서는 사진 속 물체의 위치와 이름을 알려 주는 어노테이션이 필요합니다.

예를 들어 책 두 권이 있다면 각각의 책을 따로 상자로 표시합니다.

```text
+-----------------------------+
|       [ book ] [ book ]     |
|                             |
|                [ clothes ]  |
|                             |
+-----------------------------+
```

### 좋은 Bounding Box

- 물체를 가능한 한 정확하게 감쌉니다.
- 다른 물체를 불필요하게 포함하지 않습니다.
- 물체가 잘리지 않았다면 전체가 들어가도록 합니다.
- 서로 다른 물체를 하나의 상자로 합치지 않습니다.

### 왜 한 물체씩 표시할까요?

우리 앱은 **검출된 prediction 하나를 물체 하나로 보고 개수를 셉니다.**

따라서 책 두 권을 하나의 박스로 표시하면 AI가 “책 1개”라고 배울 가능성이 생깁니다.

### 학생 활동

같은 사진을 두 명이 각각 라벨링한 뒤 상자를 비교합니다.

- 어느 상자가 더 정확한가?
- 두 사람이 다르게 판단한 이유는 무엇인가?
- 애매한 물체를 어떻게 처리할 것인가?

이 과정은 단순한 클릭 실습이 아니라 **데이터를 만드는 사람의 판단**을 배우는 활동입니다.
