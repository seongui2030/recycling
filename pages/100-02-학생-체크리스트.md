# 100-02. 학생 체크리스트

> **하나씩 체크하면 끝까지 갈 수 있습니다**

- [ ] GitHub 저장소를 열었다.
- [ ] VS Code에서 프로젝트 폴더를 열었다.
- [ ] Node.js가 설치되어 있다.
- [ ] `npm install`을 실행했다.
- [ ] `npm run dev`가 실행된다.
- [ ] DEMO MODE에서 사진 결과가 나온다.
- [ ] Roboflow 프로젝트를 만들었다.
- [ ] 6개 class 이름을 통일했다.
- [ ] Bounding Box 어노테이션을 했다.
- [ ] Dataset Version을 만들었다.
- [ ] 모델을 Test했다.
- [ ] API Key와 Model ID를 준비했다.
- [ ] Supabase 프로젝트를 만들었다.
- [ ] `schema.sql`을 실행했다.
- [ ] Google Provider를 활성화했다.
- [ ] `.env.local`을 설정했다.
- [ ] Google 로그인이 된다.
- [ ] 기부 기록이 저장된다.
- [ ] Vercel에 배포했다.
- [ ] 스마트폰에서 최종 테스트했다.

마지막으로 친구에게 앱의 전체 흐름을 1분 안에 설명해 보세요.
