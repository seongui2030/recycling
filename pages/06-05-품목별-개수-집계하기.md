# 06-05. 품목별 개수 집계하기

> **같은 이름을 모아 숫자로 바꾸기**

우리 앱에서 가장 중요한 작은 함수 중 하나입니다.

```javascript
function groupPredictions(predictions) {
  const result = {}
  for (const p of predictions) {
    const key = p.class
    result[key] = (result[key] || 0) + 1
  }
  return result
}
```

예를 들어:

```json
[
  {"class":"book"},
  {"class":"book"},
  {"class":"shoes"}
]
```

를 넣으면:

```json
{
  "book": 2,
  "shoes": 1
}
```

이 됩니다.
