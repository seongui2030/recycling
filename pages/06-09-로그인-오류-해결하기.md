# 06-09. 로그인 오류 해결하기

> **에러 메시지를 읽으면 해결책이 보입니다**

첨부된 로그인 가이드에서 소개한 대표적인 오류를 우리 프로젝트에 맞게 정리합니다.

### 1. redirect_uri_mismatch

**증상:** Google 화면에서 redirect 오류

**확인:** Google Cloud와 Supabase의 callback/redirect 설정

첨부 가이드의 핵심 해결 방향은 승인된 리디렉션 URI를 정확히 확인하는 것입니다. fileciteturn0file0L155-L161

### 2. Vercel에서 undefined

**증상:** 로컬에서는 되는데 배포하면 안 됨

**확인:**

```text
VITE_SUPABASE_URL
VITE_SUPABASE_PUBLISHABLE_KEY
```

환경변수 이름이 코드와 같은지 확인합니다.

첨부 가이드에서도 `VITE_` 접두사 누락과 재배포 필요성을 주요 원인으로 설명합니다. fileciteturn0file0L163-L171

### 3. getUser 오류

먼저 브라우저의 로그인 상태를 확인합니다.

```javascript
const { data: auth } = await supabase.auth.getUser()
console.log(auth?.user)
```

사용자가 `null`이라면 로그인 세션부터 확인합니다.

### 디버깅 순서

```text
로그인 버튼
→ Google
→ Supabase
→ 세션
→ getUser
→ DB 저장
```

문제가 있는 단계만 집중합니다.
