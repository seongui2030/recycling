# 07-10. 서비스 개선 회의

> **완성한 뒤에는 사용자의 눈으로 다시 봅니다**

앱을 만든 팀이 직접 사용하는 것과 다른 사람이 사용하는 것은 다릅니다.

### 친구에게 5분 테스트를 부탁합니다

친구에게 설명을 최소화하고 다음을 시켜 봅니다.

```text
Google 로그인
→ 사진 촬영
→ 결과 확인
→ 수정
→ 기부 등록
```

그리고 관찰합니다.

- 어디에서 멈추었는가?
- 어떤 버튼을 찾지 못했는가?
- 어떤 단어를 이해하지 못했는가?
- AI 결과를 믿어 버리지는 않았는가?

### 개선 회의

팀별로:

```text
가장 불편했던 점 1개
가장 좋은 점 1개
다음에 바꿀 점 1개
```

를 정합니다.

서비스 개발에서 중요한 것은 “내가 만든 것이 완벽하다”가 아니라 **사용자의 경험을 관찰하고 다시 개선하는 것**입니다.
