# 03-07. 기부 내역 저장하기

> **AI 결과를 데이터베이스의 기록으로 바꾸기**

우리 프로젝트의 저장 과정은 두 번의 insert로 생각하면 쉽습니다.

### 1단계: 기부 전체 저장

```javascript
const { data: donation, error } = await supabase
  .from('donations')
  .insert({
    user_id: currentUser.id,
    total_count: total,
    status: 'confirmed',
  })
  .select()
  .single()
```

### 2단계: 품목별 저장

```javascript
const rows = Object.entries(counts).map(([category, quantity]) => ({
  donation_id: donation.id,
  category,
  quantity,
}))
```

그리고:

```javascript
await supabase.from('donation_items').insert(rows)
```

실제 `App.jsx`는 기부를 먼저 저장하고, 생성된 `donation.id`를 이용해 품목 행을 저장합니다. 또한 각 class의 평균 confidence도 계산해 저장하도록 되어 있습니다. fileciteturn6file0

### 중요한 순서

```text
로그인 확인
→ AI 결과 확인
→ 사람이 수정
→ donations 저장
→ donation_items 저장
```

따라서 AI가 틀린 결과를 그대로 데이터베이스에 넣는 것이 아니라 **사람이 검수한 결과를 저장**합니다.
