
> **숫자가 이상해지지 않도록 데이터에 규칙을 줍니다**

`schema.sql`에는 다음과 같은 제약이 있습니다.

```sql
total_count integer not null default 0 check (total_count >= 0)
```

즉, 총 개수는 음수가 될 수 없습니다. fileciteturn10file0

품목 수량도 마찬가지입니다.

```sql
quantity integer not null default 0 check (quantity >= 0)
```

이런 규칙을 데이터베이스에 넣으면 프로그램에 실수가 생겨도 잘못된 데이터를 막는 데 도움이 됩니다.

## 왜 화면에서만 막지 않을까요?

React에서도 `−` 버튼을 0일 때 비활성화할 수 있습니다.

하지만 데이터베이스에도 규칙을 두면 **다른 프로그램이나 잘못된 요청이 들어와도 마지막 방어선**이 됩니다.

데이터베이스 설계는 단순히 표를 만드는 일이 아니라 데이터가 지켜야 할 약속을 만드는 일입니다.
