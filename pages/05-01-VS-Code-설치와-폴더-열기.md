# 05-01. VS Code 설치와 폴더 열기

> **코드가 머무를 집을 만듭니다**

VS Code는 코드를 작성하고 파일을 관리하는 편집기입니다.

### 따라 하기

1. VS Code를 설치합니다.
2. GitHub 저장소를 내려받습니다.
3. VS Code에서 폴더를 엽니다.
4. 왼쪽 Explorer에서 `src`, `api`, `supabase` 폴더를 확인합니다.

우리 저장소에는 다음과 같은 핵심 파일이 있습니다.

```text
recycling/
├── api/
│   └── detect.js
├── src/
│   ├── App.jsx
│   ├── main.jsx
│   ├── styles.css
│   └── supabase.js
├── supabase/
│   └── schema.sql
├── package.json
└── README.md
```

실제 저장소의 `src`에는 이 네 파일이 있으며 `api/detect.js`와 `supabase/schema.sql`도 포함되어 있습니다. fileciteturn5file0

### Explorer 사용법

파일을 클릭하면 내용을 볼 수 있습니다.

처음에는 “이 파일을 지워도 될까?”라는 불안이 생길 수 있습니다. 그래서 수업 중에는 **교사가 지정한 파일만 수정**합니다.
