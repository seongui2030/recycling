
> **사진 한 장이 기부 기록이 되기까지**

전체 흐름을 한 장의 그림처럼 기억해 봅시다.

```text
① 사진 촬영
   ↓
② React가 Data URL 생성
   ↓
③ POST /api/detect
   ↓
④ Vercel Function
   ↓
⑤ Roboflow Inference
   ↓
⑥ prediction JSON
   ↓
⑦ React가 class별 집계
   ↓
⑧ 사람이 + / − 검수
   ↓
⑨ Supabase donations
   ↓
⑩ Supabase donation_items
```

이 구조를 알면 어느 부분에서 오류가 생겼는지도 추측할 수 있습니다.

- 사진이 안 보인다 → 브라우저/파일 입력 확인
- API 오류 → `/api/detect` 확인
- Roboflow 오류 → API Key/Model ID 확인
- 로그인 오류 → Supabase Auth 확인
- 저장 오류 → RLS/테이블 확인
- 배포 후 오류 → Vercel 환경변수 확인

좋은 개발자는 모든 코드를 외우는 사람이 아니라 **문제가 어느 구간에 있는지 나눠 생각할 수 있는 사람**입니다.
