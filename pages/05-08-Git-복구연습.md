
> **개발자의 안전벨트는 버전 관리입니다**

코드를 수정하다 보면 실수할 수 있습니다.

그래서 Git의 commit을 “저장 지점”으로 생각합니다.

```bash
git status
git add .
git commit -m "작동하는 상태 저장"
git push
```

## 실습

1. 화면의 문구를 조금 수정합니다.
2. Git status를 확인합니다.
3. commit합니다.
4. 다시 문구를 수정합니다.
5. GitHub에서 commit 기록을 확인합니다.

학생에게 중요한 것은 복잡한 Git 명령을 외우는 것이 아니라 **작업의 상태를 기록하는 습관**입니다.
