# 04-02. HTTP 요청과 응답

> **브라우저와 서버가 주고받는 편지**

브라우저가 서버에 무언가를 부탁할 때 HTTP 요청을 보냅니다.

예:

```javascript
const res = await fetch('/api/detect', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ image: dataUrl }),
})
```

우리 프로젝트의 `App.jsx`도 실제로 이 방법으로 `/api/detect`에 사진을 보냅니다. fileciteturn6file0

서버는 응답합니다.

```javascript
return res.status(200).json(data)
```

즉:

```text
요청(Request)
  ↓
서버 처리
  ↓
응답(Response)
```

### POST와 GET

- `GET` → 정보를 가져올 때
- `POST` → 정보를 보내거나 생성할 때

사진을 분석해 달라는 요청은 이미지 데이터를 보내야 하므로 POST를 사용합니다.

### 상태 코드

- `200` → 성공
- `400` → 요청이 잘못됨
- `405` → 허용하지 않는 HTTP 메서드
- `500` → 서버에서 문제가 생김

`api/detect.js`는 POST가 아니면 405를 반환하고, 이미지가 없으면 400을 반환하도록 작성되어 있습니다. fileciteturn7file0
