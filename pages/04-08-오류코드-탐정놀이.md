# 04-08. 오류 코드 탐정놀이

> **숫자를 보면 문제의 위치를 추측할 수 있습니다**

웹 개발에서 상태 코드는 중요한 단서입니다.

| 코드 | 쉬운 의미 |
|---|---|
| 200 | 성공 |
| 400 | 요청이 잘못됨 |
| 401 | 인증이 필요하거나 인증 문제가 있음 |
| 403 | 권한이 없음 |
| 404 | 주소를 찾지 못함 |
| 405 | 허용하지 않은 요청 방식 |
| 500 | 서버 내부 문제 |

`api/detect.js`는 POST가 아니면 405, 이미지가 없으면 400을 반환하도록 작성되어 있습니다. fileciteturn7file0

### 탐정 활동

친구가 “안 돼요”라고 말하면 먼저:

```text
몇 번 오류인가요?
어느 화면에서 발생했나요?
버튼을 누르기 전인가요, 누른 후인가요?
```

를 묻습니다.

이것만으로도 문제 범위를 크게 줄일 수 있습니다.
