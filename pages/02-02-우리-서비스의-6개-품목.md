
> **AI가 말할 수 있는 단어를 먼저 정합니다**

모델을 학습시키기 전에 AI가 어떤 이름을 사용할지 정해야 합니다.

우리 프로젝트는 다음 6개 class를 사용합니다.

| 코드 이름 | 화면 이름 |
|---|---|
| `clothes` | 의류 |
| `shoes` | 신발 |
| `book` | 도서 |
| `kitchenware` | 주방용품 |
| `small_appliance` | 소형가전 |
| `bag` | 가방 |

이 이름은 코드에서 중요한 약속입니다. `book`이라고 학습했는데 앱에서 `books`라고 처리하면 서로 다른 이름이 됩니다.

따라서 **데이터셋의 클래스 이름과 웹앱의 클래스 이름을 똑같이 유지**하는 것이 좋습니다.

`App.jsx`의 `LABELS` 객체도 이 6개 class를 한글 이름으로 바꾸어 화면에 보여주는 역할을 합니다. fileciteturn6file0

## 미니 활동

다음 물건을 보고 어느 class에 넣을지 토론해 보세요.

- 책가방 → `bag`
- 운동화 → `shoes`
- 냄비 → `kitchenware`
- 전기포트 → `small_appliance`

애매한 물건이 생기면 그것은 데이터 설계의 문제를 발견한 것입니다. AI에게 맡기기 전에 사람이 먼저 분류 기준을 정해야 합니다.
