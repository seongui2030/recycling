# 05-09. 브라우저 개발자 도구

> **웹브라우저 안에 작은 실험실이 있습니다**

Chrome 개발자 도구에서는 Console, Network 등을 볼 수 있습니다.

### Console

JavaScript에서:

```javascript
console.log('현재 사용자:', user)
```

처럼 기록하면 Console에서 확인할 수 있습니다.

### Network

사진을 선택하면 `/api/detect` 요청이 발생하는지 볼 수 있습니다.

### 학생 실험

다음 질문에 답해 보세요.

```text
사진 선택 전에는 /api/detect 요청이 있는가?
사진 선택 후에는 있는가?
응답 상태 코드는 몇 번인가?
```

개발자 도구를 잘 사용하면 “코드가 안 돼요”가 “요청은 성공했는데 응답 데이터가 이상해요”처럼 구체적인 문제로 바뀝니다.

이것이 디버깅의 시작입니다.
