
> **내 컴퓨터의 앱을 다른 사람의 스마트폰으로**

## 🌍 교실에서 세상으로

이제 SDG 4에서 배운 것과 SDG 9의 기술을 하나의 서비스로 묶어 SDG 12를 향한 작은 해결책을 세상에 공개합니다. Vercel 배포를 통해 **“내가 배운 기술이 실제 사람에게 쓰일 수 있다”**는 경험을 완성합니다.


개발 중인 앱은 보통 내 컴퓨터에서만 열립니다.

배포는 이 앱을 인터넷을 통해 다른 사람이 사용할 수 있도록 올리는 과정입니다.

우리 프로젝트에서는 Vercel을 사용합니다.

```text
내 PC
  ↓ GitHub
Vercel
  ↓
인터넷
  ↓
스마트폰
```

Vercel 공식 문서에서는 Git 저장소를 연결해 push마다 배포가 발생하는 방식을 대표적인 방법으로 안내합니다. citeturn1search3

현재 프로젝트에는 배포 예시 주소도 있습니다.

```text
https://recycling-iota.vercel.app/
```

## 배포 전 생각

로컬에서는:

```text
localhost
```

를 사용합니다.

배포 후에는:

```text
https://내앱.vercel.app
```

가 됩니다.

그러므로 Google OAuth와 Supabase Auth도 **배포된 주소를 알고 있어야 합니다.**
