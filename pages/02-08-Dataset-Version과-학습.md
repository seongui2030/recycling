# 02-08. Dataset Version과 학습

> **공부 자료를 한 권의 교과서로 묶습니다**

Roboflow에서 Dataset Version은 학습에 사용할 데이터의 한 버전입니다.

### 왜 버전이 필요할까요?

학생 A팀은 사진 300장, B팀은 500장, C팀은 700장을 준비할 수 있습니다. 또한 이미지 크기나 augmentation 설정도 달라질 수 있습니다.

버전으로 묶어 두면 “우리가 어떤 데이터로 학습했는가?”를 기록할 수 있습니다.

### 기본 흐름

```text
Upload
  ↓
Annotate
  ↓
Dataset 확인
  ↓
Generate Dataset
  ↓
Train
  ↓
Test
```

### augmentation 생각하기

학습 데이터가 너무 적을 때 이미지의 방향, 밝기, 크기 등을 변화시켜 다양한 상황을 경험하게 하는 방법이 있습니다.

하지만 augmentation을 많이 한다고 무조건 좋아지는 것은 아닙니다. 실제 사용 환경과 관계없는 변형을 과도하게 넣으면 오히려 학습이 어려워질 수 있습니다.

### 수행평가 기록

학생은 다음을 기록합니다.

- 데이터 개수
- class별 데이터 분포
- version 번호
- 학습 날짜
- Test 결과
- 개선한 점
