# 04-07. 서버리스 함수란 무엇일까요?

> **서버 컴퓨터를 직접 관리하지 않고도 서버 코드를 실행하기**

우리 프로젝트의 `api/detect.js`는 Vercel에서 함수 형태로 실행됩니다.

```javascript
export default async function handler(req, res) {
  // 요청 처리
}
```

Vercel의 Vite 문서에서도 프로젝트 루트의 `api` 디렉터리에 함수를 두는 방식을 안내합니다. citeturn1search0

### 학생에게 필요한 이해

서버리스라는 이름 때문에 “서버가 없는 것”처럼 느껴지지만 실제 의미는 **서버의 컴퓨터를 직접 관리하지 않고 플랫폼이 실행 환경을 제공한다**는 쪽에 가깝습니다.

우리 서비스에서는 서버리스 함수가 Roboflow API Key를 숨기고 요청을 전달하는 역할을 합니다.

```text
브라우저 → 서버리스 함수 → Roboflow
```

이 구조는 작은 프로젝트에서도 백엔드의 역할을 체험하게 해 줍니다.
