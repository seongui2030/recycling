# 07-09. 배포 후 문제해결

> **로컬 성공과 배포 성공은 같은 것이 아닙니다**

로컬에서 잘 작동했는데 Vercel에서는 문제가 생길 수 있습니다.

### 가장 먼저 확인할 것

```text
□ 환경변수
□ Build 로그
□ Function 로그
□ Google Redirect URL
□ Supabase Site URL
□ 실제 배포 주소
```

특히 Vercel에 환경변수를 새로 추가했다면 재배포가 필요할 수 있습니다. 첨부된 로그인 가이드도 이 문제를 주요 원인으로 설명합니다. fileciteturn0file0L163-L171

Vercel의 배포 문서에서도 Deployment 상세 화면에서 build 정보와 logs를 확인할 수 있다고 안내합니다. citeturn1search3

### 문제를 두 단계로 나누기

```text
빌드 자체가 실패
→ 코드/패키지/환경변수 문제

빌드는 성공했지만 기능 실패
→ API/Auth/DB/Redirect 문제
```

이렇게 나누면 훨씬 차분하게 해결할 수 있습니다.
