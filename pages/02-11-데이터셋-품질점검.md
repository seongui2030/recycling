
> **사진의 수보다 사진의 질을 먼저 살펴봅니다**

모델을 학습하기 전에 데이터셋을 검사합니다.

## 점검 순서

```text
1. class 이름 확인
2. 빈 라벨 확인
3. 박스가 너무 큰 이미지 확인
4. 물체가 잘리지 않았는지 확인
5. 한 class에만 사진이 몰리지 않았는지 확인
```

## 학생 활동

각 팀에서 가장 잘 라벨링된 사진 3장과 가장 어려운 사진 3장을 골라 발표합니다.

좋은 데이터는 “예쁜 사진”이 아니라 **AI가 배워야 할 정보를 정확하게 담은 사진**입니다.

## 어려운 사진도 중요합니다

흐린 사진, 일부가 가려진 물체, 어두운 배경의 물체가 실제 서비스에서 등장할 수 있습니다.

따라서 어려운 사례를 무조건 버리지 말고 별도의 폴더나 목록으로 관리합니다.

이렇게 하면 나중에 Test 결과와 비교하여 “우리 AI가 어떤 상황에서 약한가?”를 찾을 수 있습니다.
