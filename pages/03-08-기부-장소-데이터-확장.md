# 03-08. 기부 장소 데이터 확장

> **기부한 날뿐 아니라 어디에서 기부했는지도 기록해 볼까요?**

처음 프로젝트의 `donations` 테이블에는 기부 날짜가 자동으로 기록됩니다. 실제 서비스로 확장한다면 기부 장소를 추가할 수 있습니다.

예를 들어:

```sql
alter table public.donations
add column place text;
```

그리고 React에서:

```javascript
.insert({
  user_id: currentUser.id,
  total_count: total,
  status: 'confirmed',
  place,
})
```

처럼 저장할 수 있습니다.

### 주의

장소는 개인정보와 연결될 수 있습니다. 학생 프로젝트에서는 정확한 집 주소를 저장하지 말고 학교, 아름다운가게 지점 등 **서비스에 필요한 범위의 장소**만 사용하도록 지도합니다.

데이터베이스 설계에서 “무엇을 저장할 수 있는가?”와 “무엇을 저장해야 하는가?”는 다른 질문입니다.
