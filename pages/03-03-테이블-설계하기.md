# 03-03. 테이블 설계하기

> **데이터를 표로 생각하면 SQL이 쉬워집니다**

먼저 종이에 표를 그려 봅시다.

### profiles

| id | email | name | role |
|---|---|---|---|
| 사용자 ID | 이메일 | 이름 | donor |

### donations

| id | user_id | donation_date | total_count | status |
|---|---|---|---|---|
| 기부 ID | 사용자 | 기부일 | 총 개수 | 상태 |

### donation_items

| id | donation_id | category | quantity | confidence |
|---|---|---|---|---|
| 품목 ID | 기부 ID | 품목 | 수량 | 평균 신뢰도 |

### 관계

```text
auth.users
    │
    └── profiles

auth.users
    │
    └── donations
             │
             └── donation_items
```

한 사용자가 여러 번 기부할 수 있고, 한 번의 기부에는 여러 품목이 들어갈 수 있습니다.

이 구조는 **1명의 사용자 : 여러 기부 : 여러 기부 품목**이라는 관계를 표현합니다.
