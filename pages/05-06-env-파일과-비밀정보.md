
> **환경변수는 프로그램의 설정을 바깥에 두는 방법입니다**

환경변수는 코드와 설정값을 분리할 때 사용합니다.

예:

```env
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=...
VITE_DEMO_MODE=true
```

그리고 실제 Roboflow 연결에서는:

```env
ROBOFLOW_API_KEY=...
ROBOFLOW_MODEL_ID=recycling-items/1
```

를 서버 환경에 둡니다.

## 절대 하지 않을 것

```text
❌ API Key를 App.jsx에 직접 작성
❌ 비밀키를 README.md에 작성
❌ .env.local을 GitHub에 push
❌ 친구에게 비밀키를 채팅으로 전송
```

## 확인 방법

`.gitignore`에 환경변수 파일이 제외되어 있는지 확인합니다.

```text
.env
.env.local
```

환경변수는 “외워야 할 보안 기술”이라기보다 **코드와 설정을 분리하는 생활 습관**이라고 생각하세요.
