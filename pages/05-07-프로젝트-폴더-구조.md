# 05-07. 프로젝트 폴더 구조 읽기

> **파일을 보면 프로그램의 설계가 보입니다**

우리 프로젝트의 중요한 구조는 다음과 같습니다.

```text
recycling/
├── api/
│   └── detect.js
├── src/
│   ├── App.jsx
│   ├── main.jsx
│   ├── styles.css
│   └── supabase.js
├── supabase/
│   └── schema.sql
└── package.json
```

### 역할

- `App.jsx` → 화면과 주요 동작
- `main.jsx` → React 시작점
- `styles.css` → 디자인
- `supabase.js` → Supabase 연결
- `api/detect.js` → Roboflow 서버 요청
- `schema.sql` → 데이터베이스 설계
- `package.json` → 프로젝트 설정과 패키지

저장소의 실제 파일 구조도 이 역할 분리를 보여 줍니다. fileciteturn5file0turn4file0
