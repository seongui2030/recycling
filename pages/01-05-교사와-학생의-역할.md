
> **교사는 답을 주기보다 길을 밝혀 줍니다**

이 책은 학생이 혼자 모든 문제를 해결해야 한다는 뜻이 아닙니다.

교사는 다음을 준비합니다.

- 계정 생성이 필요한 서비스 안내
- 컴퓨터실 환경 점검
- 공용 실습 데이터 준비
- 오류가 반복될 때 공통 해결책 정리
- 개인정보와 API Key 관리

학생은 다음을 담당합니다.

- 안내된 순서대로 직접 실행
- 결과 화면 확인
- 오류 메시지 읽기
- 자신의 말로 기능 설명
- 작은 기능 하나를 스스로 변경

특히 Google, Supabase, Roboflow, Vercel 계정은 학생 개인 정보와 연결될 수 있으므로 학교의 계정 사용 규칙을 우선합니다.

수업의 목표는 “교사가 대신 만들어 준 앱”이 아니라 **학생이 완성 과정에 참여한 앱**입니다.
