
> **내 코드의 안전한 사진첩을 만들기**

Git은 코드의 변경 이력을 기록하는 도구이고, GitHub는 그 저장소를 온라인에서 관리하는 서비스입니다.

## 기본 흐름

```bash
git add .
git commit -m "첫 번째 저장"
git push
```

쉽게 말하면:

- `git add .` → 바뀐 파일을 저장할 목록에 올립니다.
- `git commit` → 현재 상태를 한 번 기록합니다.
- `git push` → GitHub로 보냅니다.

## 왜 Git을 배울까요?

실수로 코드를 바꾸었을 때 이전 버전을 찾기 쉽습니다.
