# 02-09. Test와 confidence 읽기

> **AI가 얼마나 자신 있게 말하는지 살펴보기**

Roboflow prediction에는 `confidence`가 들어옵니다.

예:

```json
{
  "class": "book",
  "confidence": 0.94
}
```

0.94는 94%처럼 보이지만, 학생에게 “AI가 실제로 94% 확률로 정답이다”라고 단순하게 설명해서는 안 됩니다. 이 값은 모델의 검출 신뢰도 점수로 이해하는 것이 좋습니다.

우리 앱은 화면에서 다음처럼 보여 줍니다.

```text
도서 94%
```

### 생각해 보기

다음 결과가 있다면 어떤 결과를 먼저 확인해야 할까요?

```text
book 0.96
book 0.92
shoes 0.51
```

보통 낮은 confidence 결과부터 실제 사진을 확인해 보는 것이 좋은 검수 전략이 될 수 있습니다.

### AI 평가에서 중요한 질문

- 틀린 물체를 찾았는가? → False Positive
- 물체를 놓쳤는가? → False Negative
- 다른 class로 잘못 분류했는가?
- 특정 배경에서만 잘 작동하는가?

AI 모델의 숫자를 보는 것보다 **실제 사진에서 어떤 실수를 했는지**를 보는 습관을 길러 봅시다.
