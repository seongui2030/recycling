# 02-01. 컴퓨터 비전과 Object Detection

> **사진을 숫자로 바꾸고, 숫자에서 물체를 찾는 AI**

## 🌱 SDG 12를 향한 첫 번째 기술

**SDG 12의 자원순환 문제를 해결하기 위해, 우리는 SDG 4의 배움으로 AI의 눈을 만듭니다.** Roboflow에서 데이터를 모으고 어노테이션하고 모델을 시험하면서 “AI는 어떻게 물건을 알아볼까?”를 탐구합니다.


사람은 사진을 보면 “책 두 권, 신발 한 켤레, 옷 한 벌”이라고 자연스럽게 말합니다. 컴퓨터는 그렇지 않습니다. 컴퓨터는 이미지를 픽셀이라는 숫자의 배열로 받아들입니다.

컴퓨터 비전은 이미지나 영상에서 의미 있는 정보를 찾아내는 기술입니다.

우리는 그중에서도 **Object Detection(객체 탐지)**을 사용합니다.

객체 탐지는 보통 다음 세 가지 정보를 함께 줍니다.

- 어떤 물체인가? → `class`
- 얼마나 확신하는가? → `confidence`
- 어디에 있는가? → `x`, `y`, `width`, `height`

우리 프로젝트의 Roboflow 결과 예시는 다음과 같은 구조입니다.

```json
{
  "class": "book",
  "confidence": 0.94,
  "x": 250,
  "y": 250,
  "width": 260,
  "height": 220
}
```
