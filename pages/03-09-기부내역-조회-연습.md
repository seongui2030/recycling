# 03-09. 기부내역 조회 연습

> **저장한 데이터를 다시 화면으로 가져오기**

저장만 하고 끝내지 말고 데이터를 다시 읽어 봅니다.

기본적인 Supabase 조회는 다음과 같은 모양입니다.

```javascript
const { data, error } = await supabase
  .from('donations')
  .select('*')
  .order('donation_date', { ascending: false })
```

이때 RLS가 적용되어 있으면 로그인 사용자가 허용된 행만 조회할 수 있습니다.

### 학생 미션

“내가 지금까지 몇 개를 기부했을까?”

를 화면에 표시해 봅니다.

```text
총 기부 횟수: 3회
총 기부 물품: 17개
```

다음 단계에서는 품목별 누적 통계를 만들어 볼 수 있습니다.

```text
의류 7
도서 5
신발 3
가방 2
```

데이터베이스가 단순 저장소가 아니라 **서비스의 기억**이라는 것을 경험하는 활동입니다.
