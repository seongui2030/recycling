# 05-03. Git Bash와 기본 명령

> **검은 창과 친해지는 가장 쉬운 방법**

Git Bash는 명령어를 입력하여 폴더를 이동하고 프로그램을 실행하는 터미널입니다.

### 자주 쓰는 명령

```bash
pwd
```

현재 위치를 봅니다.

```bash
ls
```

파일과 폴더를 봅니다.

```bash
cd recycling
```

`recycling` 폴더로 이동합니다.

```bash
npm install
```

프로젝트에 필요한 패키지를 설치합니다.

```bash
npm run dev
```

개발 서버를 실행합니다.

### 기억할 한 가지

명령어는 외우는 것이 아니라 **필요할 때 책에서 복사해서 실행해도 됩니다.**

중요한 것은 명령어를 실행한 뒤 결과를 읽는 습관입니다.
