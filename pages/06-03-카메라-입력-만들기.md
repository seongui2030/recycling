# 06-03. 카메라 입력 만들기

> **스마트폰을 앱의 눈으로 사용하기**

현재 프로젝트에서는 HTML의 파일 입력에 다음 속성을 사용합니다.

```jsx
<input
  type="file"
  accept="image/*"
  capture="environment"
  onChange={onPhoto}
/>
```

- `type="file"` → 파일 선택
- `accept="image/*"` → 이미지 선택
- `capture="environment"` → 모바일에서 후면 카메라 사용을 유도
- `onChange` → 사진이 선택되었을 때 함수 실행

`onPhoto`에서는 선택한 파일을 `FileReader`로 Data URL로 바꿉니다.

```javascript
reader.readAsDataURL(file)
```

그리고:

```javascript
setImageUrl(dataUrl)
```

로 화면에 사진을 보여 줍니다. 실제 구현은 `App.jsx`의 `dataUrlFromFile()`과 `onPhoto()`에 들어 있습니다. fileciteturn6file0

### 촬영 팁

- 밝은 곳에서 찍습니다.
- 물건이 서로 겹치지 않게 놓습니다.
- 사진 한 장에 너무 많은 물건을 넣지 않습니다.

이 작은 촬영 습관이 AI의 성능에도 영향을 줄 수 있습니다.
