# 02-05. 데이터 업로드와 클래스

> **AI에게 이름표를 붙여 주는 시간**

사진을 업로드한 뒤 가장 먼저 확인할 것은 **class 이름**입니다.

우리 앱은 다음 문자열을 기대합니다.

```text
clothes
shoes
book
kitchenware
small_appliance
bag
```

### 외부 데이터셋을 사용할 때

Roboflow Universe에서 데이터셋을 가져올 수도 있습니다. 이때 외부 프로젝트의 class 이름이 우리 프로젝트와 다를 수 있습니다.

예를 들어:

```text
shirt  → clothes
pants  → clothes
boot   → shoes
novel  → book
```

처럼 Remap Classes를 사용해 하나의 기준으로 맞출 수 있습니다.

### 왜 이름 통일이 중요할까요?

웹앱은 다음처럼 `class`를 키로 사용합니다.

```javascript
const key = p.class
result[key] = (result[key] || 0) + 1
```

따라서 `book`과 `books`는 다른 품목으로 집계됩니다.

**데이터와 프로그램이 같은 언어를 사용하도록 만드는 것**이 데이터베이스와 AI 서비스 연결의 첫걸음입니다.
