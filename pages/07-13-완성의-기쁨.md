# 07-13. 완성의 기쁨

> **스마트폰에서 내 앱이 열리는 순간**

처음에는 낯선 단어가 많았습니다.

```text
Roboflow
Supabase
React
API
Git
Vercel
OAuth
```

하지만 마지막에는 이 단어들이 하나의 서비스로 연결됩니다.

```text
사진
 ↓
AI
 ↓
품목과 개수
 ↓
사람의 확인
 ↓
기부 기록
 ↓
인터넷 서비스
```

여러분이 만든 것은 단순한 화면이 아닙니다.

누군가 기부할 물건을 정리할 때 시간을 아껴 주고, 기부 기록을 남기고, 자원순환이라는 사회적 가치를 보여 주는 작은 도구입니다.

프로그램 개발을 처음 시작한 학생에게 가장 큰 변화는 코드 한 줄을 더 외우는 것이 아닙니다.

> **“나는 기술을 사용할 수 있고, 필요하다면 새로운 것을 만들어 볼 수 있다.”**

라는 경험입니다.

이 책의 마지막 페이지를 덮은 뒤에도 여러분의 다음 프로젝트가 시작되기를 바랍니다.
