# 기부 비서 — AI로 배우는 컴퓨터 비전과 자원순환

> ## 배우고(SDG 4), 만들고(SDG 9), 나누며(SDG 12)
> ## 인공지능으로 지속가능한 미래를 설계합니다.

**SDG 12를 해결하기 위해 SDG 4의 교육과 SDG 9의 디지털 기술을 활용합니다.**

《기부 비서》는 단순히 React를 배워 앱을 만드는 책이 아닙니다. 학생들이 생활 속 자원순환 문제를 발견하고, 인공지능을 배우고, 디지털 기술을 연결하여 실제로 작동하는 해결 서비스를 만드는 **프로젝트형 인공지능 기초 교과서**입니다.

스마트폰으로 기부 물품을 촬영하면 컴퓨터 비전 AI가 품목을 찾아내고, 같은 품목의 개수를 합산한 뒤 사람이 결과를 확인하여 Supabase에 기록합니다. 마지막에는 Vercel을 통해 인터넷에서 사용할 수 있는 서비스로 배포합니다.

## 🌱 세 개의 SDG가 하나의 프로젝트에서 만납니다

### SDG 12 · 책임감 있는 소비와 생산 — 우리가 해결하고 싶은 문제

아직 사용할 수 있는 물건을 버리는 대신 기부하고 재사용하는 자원순환을 생각합니다. 《기부 비서》에서 SDG 12는 **우리가 기술을 배우는 이유**입니다.

### SDG 4 · 양질의 교육 — 우리가 배우는 방법

컴퓨터 비전, 데이터베이스, 웹, API, 인증, 배포를 실제 프로젝트 안에서 배우며 “AI를 소비하는 학생”에서 “AI로 무언가를 만들어 보는 학생”으로 한 걸음 나아갑니다.

### SDG 9 · 산업·혁신·인프라 — 우리가 만드는 방법

Roboflow, Supabase, React, Vite, GitHub, Vercel을 하나의 서비스로 연결합니다. 기술 자체가 목적이 아니라 **기술로 무엇을 할 수 있는가**를 경험합니다.

## 📷 우리가 만드는 서비스

```text
사진 촬영
   ↓
컴퓨터 비전 AI
   ↓
품목별 분류·개수 계산
   ↓
사람의 확인·수정
   ↓
Supabase에 기부 기록 저장
   ↓
Vercel 배포
   ↓
자원순환과 나눔에 참여
```

## 📚 책의 7개 장면

이 책은 본문상 7개 장으로 구성됩니다. 첫 장은 학습을 시작하는 문이며, 뒤의 여섯 장은 기술과 서비스 구축의 여정입니다.

1. **01. 책을 시작하며** — 디지털은 어려운 기계가 아니라 따뜻한 도구입니다.
2. **02. 컴퓨터 비전** — AI에게 세상을 보는 방법을 가르칩니다.
3. **03. 데이터베이스** — AI가 본 것을 데이터로 기억합니다.
4. **04. 브라우저와 서버** — 웹과 AI가 대화하는 방법을 배웁니다.
5. **05. 개발 준비** — 디지털 세상을 만드는 도구 상자를 준비합니다.
6. **06. 웹 프레임워크와 로그인** — 사람이 사용할 수 있는 AI 서비스로 만듭니다.
7. **07. 앱 배포** — 교실에서 세상으로 서비스를 보냅니다.

## 대상

- 일반계 고등학교 「인공지능 기초」 수업
- 컴퓨터 사용이 익숙하지 않은 학생
- 코딩을 처음 만나는 학생
- 사회문제와 AI 서비스를 연결해 보고 싶은 학생

## 완성 결과

학생은 책의 순서대로 따라 하면서 다음 서비스를 완성합니다.

1. 스마트폰 카메라로 기부 물품 사진 선택
2. Roboflow Object Detection으로 물품 검출
3. `class`를 품목명으로 사용하여 품목별 개수 집계
4. 사람이 `+ / −` 버튼으로 AI 결과 검수
5. Google 로그인
6. Supabase `donations`, `donation_items`에 기부 기록 저장
7. Vercel에 배포

실습 기준 저장소: https://github.com/seongui2030/recycling-wiki  
배포 예시: https://recycling-iota.vercel.app/

## 이 책의 약속

- **먼저 실행하고, 다음에 이해합니다.**
- 코드는 필요한 만큼만 복사합니다.
- 에러가 나면 실패가 아니라 디버깅 실습이 시작된 것입니다.
- 비밀키는 브라우저 코드에 넣지 않습니다.
- AI의 결과를 그대로 믿지 않고 사람이 최종 확인합니다.
- 기술을 배운 뒤에는 “이 기술로 어떤 사회문제를 해결할 수 있을까?”를 다시 묻습니다.
